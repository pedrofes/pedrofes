# 💫 Sobre mim

👨🏻‍💻 Olá! Sou Pedro Fonseca, formado em **Análise e Desenvolvimento de Sistemas** pelo Centro Universitário Facens, jornalista formado pela **UNESP** e pós-graduado com MBA em **Digital Business** pela USP Esalq.

Atualmente, estou direcionando minha carreira para a área de **Tecnologia e Desenvolvimento de Software**, com foco no desenvolvimento das minhas habilidades em **Python, SQL, bancos de dados e Programação Orientada a Objetos**.

💻 Tenho desenvolvido projetos práticos em Python para consolidar conceitos como **lógica de programação, manipulação de arquivos, persistência de dados, SQLite, consultas SQL, relacionamento entre tabelas, validação de dados e POO**.

📰 Minha trajetória profissional também inclui experiência em **jornalismo, produção de conteúdo e comunicação digital**, incluindo atuação como editor e redator da Cripto Magazine. Essa experiência me proporcionou habilidades em comunicação, pesquisa, produção de conteúdo, organização de informações e trabalho com WordPress.

🚀 Busco minha primeira oportunidade profissional na área de desenvolvimento, enquanto continuo ampliando meus conhecimentos e construindo projetos para colocar em prática os conceitos estudados.
