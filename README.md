# 💫 Sobre mim

👨🏻‍💻 Olá! Sou Pedro Fonseca, formado em **Análise e Desenvolvimento de Sistemas** pelo Centro Universitário Facens, jornalista formado pela **UNESP** e pós-graduado com MBA em **Digital Business** pela USP Esalq.

Atualmente, estou direcionando minha carreira para a área de **Tecnologia e Desenvolvimento de Software**, desenvolvendo conhecimentos em **Python, SQL, bancos de dados, Programação Orientada a Objetos, APIs e desenvolvimento web com HTML e CSS**.

💻 Tenho desenvolvido projetos práticos para consolidar conceitos como **lógica de programação, manipulação de arquivos, persistência de dados, SQLite, consultas SQL, relacionamento entre tabelas, validação de dados, Programação Orientada a Objetos, APIs, testes automatizados, Docker e deploy**.

🌐 Também venho estudando desenvolvimento web com **HTML e CSS**, aplicando conceitos como estruturação de páginas, HTML semântico, hierarquia de conteúdo, links, listas, imagens, caminhos relativos, seletores CSS, classes, cores, backgrounds e tipografia.

📰 Minha trajetória profissional inclui mais de cinco anos de experiência em **jornalismo, produção de conteúdo e comunicação digital**, com atuação em redação, edição, SEO, assessoria de imprensa e WordPress. Entre minhas experiências, atuei como editor e redator da Cripto Magazine.

🚀 Busco minha primeira oportunidade profissional na área de desenvolvimento, enquanto continuo ampliando meus conhecimentos e construindo projetos para colocar em prática os conceitos estudados.
